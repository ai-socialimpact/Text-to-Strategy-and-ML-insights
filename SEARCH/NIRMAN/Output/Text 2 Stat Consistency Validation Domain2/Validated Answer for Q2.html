Everyday Explanation of Each Methodology
RUN #1 ✓ Aligned
Paired Mean Change with Paired t-Test (Parametric Baseline)

This run sets the standard parametric baseline. It computes Pre and Post means and the mean delta on exactly matched pairs and tests whether the mean delta differs from 0. It also reports Cohen's dz as an effect size. The other runs are compared against these numbers.

Calculated Finding: Level 0.1: N = 1307, Pre 2.90/3, Post 3.96/4, mean delta 1.06, median delta 1. Improved 864 (66.11%), same 311 (23.79%), declined 132 (10.10%). Paired t(1306) = 28.11, p < 0.0001, 95% CI 0.99 to 1.14, dz = 0.78. Levels 0.2 and 0.3 have N = 0.
RUN #2 ✓ Aligned
Median Change & Wilcoxon Signed-Rank Test (Robust Non-Parametric)

Life satisfaction is a 1-5 ordinal item with many ties, so means and t-tests can mislead. Medians, the IQR of the deltas, and the Wilcoxon signed-rank test give an ordinal-appropriate check of the direction and size of the change.

Calculated Finding: Same descriptives and classification counts (N = 1307; Pre 2.90, Post 3.96; delta 1.06/1). Wilcoxon on 996 non-zero deltas gives z = 22.29, p < 0.0001, r = 0.71. IQR for delta 0 to 2. Levels 0.2 and 0.3 have no pairs.
RUN #3 ✓ Aligned
Pair-Count-Weighted Pooled Estimate vs Level-Stratified Estimates

The all-levels total mixes Point 1, 2 and 3 pairs of very different sizes. This run computes level-specific results and then rebuilds the all-levels mean delta as a pair-count-weighted average of level means. It also compares that with an equal-weighted (unweighted) average of level means. This checks that the pooled total matches the direct pooled computation and shows whether Point 1 dominates the total.

Calculated Finding: Same Level 0.1 results (N = 1307, delta 1.06, 66.11/23.79/10.10%). Direct, weighted and unweighted all-level means all equal 1.06 because only one level contributes. t = 28.11, p < 0.001 (normal approximation).
RUN #4 ✓ Aligned
5% Trimmed Mean Delta with Sign Test (Outlier-Filtered)

On a 1-5 scale, deltas range from -4 to +4. A few extreme swings, which may be careless responses, could inflate or deflate the mean. Trimming the top and bottom 5% of deltas and running a distribution-free sign test checks whether the observed direction of change holds without extreme pairs.

Calculated Finding: Same untrimmed results. Trimmed mean delta 1.07 (n = 1177), winsorized 1.06, sign test 864 up vs 132 down (z = 23.19, p < 0.0001). Robustness flag true. Levels 0.2 and 0.3 have no pairs.
RUN #5 ✓ Aligned
Rank-Order Transition Matrix & Cumulative Category Shift Analysis

This run treats the 1-5 response as ordinal categories. It builds a 5x5 Pre-to-Post transition matrix and cumulative distributions, such as the share agreeing (>= 4) before and after. Improved/Same/Declined counts derived from the matrix (above, on, or below the diagonal) are an independent cross-check of the delta-based classification. Comparing cumulative distributions shows whether the whole response distribution shifted, not just the mean.

Calculated Finding: Same results (N = 1307, delta 1.06; 864/311/132). The transition matrix cross-check matches. Agree (>=4) rose from 32.06% to 72.07% (+40.01 pp) and disagree (<=2) fell from 38.18% to 8.26%. McNemar chi2 = 422.46 and Wilcoxon z = 22.29, both p < 0.01.

5-Run Domain Explanations (Schema Context)

Run #1: Paired Mean Change with Paired t-Test (Parametric Baseline)

This run applies the schema pipeline directly. It casts keys to string, rounds Workshop_Level to 1 decimal so that 0.1 / 0.2 / 0.3 compare exactly, and sets 0 and values > 5 to NaN. The mean rose from 2.90 to 3.96 (delta +1.06, SD 1.37, 95% CI 0.99-1.14, dz 0.78, t(1306) = 28.11). The size of the change reflects the pairing design. Each person is compared with themselves, so between-person differences in baseline satisfaction drop out. Pre means near 2.9 on a 1-5 scale mean there was room to move before the ceiling. The shift from 32% to 72% agreeing suggests the whole distribution moved, not a few extreme responders. The 'no duplicate keys' result confirms the grain: one row per (participant, level, phase). The empty Level 0.2/0.3 groups return null statistics because of the n < 2 guard, and that is why the 'all levels' figure equals Level 0.1. The 1,307 are 1,307 distinct participants, because each person has only one Point 1 pair.

Run #2: Median Change & Wilcoxon Signed-Rank Test (Robust Non-Parametric)

The agreement scale is ordinal with heavy ties (only the values 1-5 and deltas of -4 to +4). This run is therefore the most appropriate in schema terms. Medians (3 to 4, delta +1) and an IQR for delta of 0 to 2 show a typical one-step improvement. The test used only the 996 non-zero deltas (864 + 132). The 311 'stayed the same' pairs are tie-discarded, which is why 996 rather than 1,307 enters the Wilcoxon. With 996 non-zero deltas the test is far from underpowered (z = 22.29, r = 0.71). It agrees with the t-test because the change is large and one-directional (about 6.5 up for every 1 down), not driven by outliers. This run also gives the clearest data-lineage explanation for the empty levels. Only one Post value exists at each of Levels 0.2 and 0.3, with no Pre to match, so the inner merge returns 0 pairs. Those are orphan rows, not a code failure.

Run #3: Pair-Count-Weighted Pooled Estimate vs Level-Stratified Estimates

This run tests whether the 'all levels' total is just Point 1 under another name, because the schema warns that Point 1/2/3 are different stages of the program. Direct pooled, pair-weighted and unweighted means all equal 1.06 and Level 0.1's share is 100%. Only one level contributes, so weighting cannot change anything. The weighted-versus-unweighted contrast it was designed to show is moot in this data. The narrative also contains a loose statement: the 143 dropped pairs are said to 'mostly reflect' the 286 zeros. Those 286 zeros are counted at row level across all Pre and Post rows, including rows that never matched, so they cannot be mapped one-to-one to pairs. The p-value here uses a normal approximation, which is acceptable because n > 30 (df = 1306), and it matches the exact t to 2 decimals.

Run #4: 5% Trimmed Mean Delta with Sign Test (Outlier-Filtered)

Life satisfaction is a self-rated item, and it could be argued that careless or extreme swings (for example -4 or +4) distort the mean. Trimming floor(0.05 x 1307) = 65 pairs from each end leaves 1,177 pairs and moves the mean delta only from 1.06 to 1.07 (winsorized 1.06). Each tail contains very few pairs, and the central mass of deltas (0, +1, +2) drives the result. The sign test (864 up vs 132 down, z = 23.19) ignores magnitude and also ignores the 311 ties, so it confirms direction only. It is very significant because the up:down ratio is about 6.5:1. The point that levels 0.2/0.3 are 'absent, not just small N' is the right domain reading, since no Pre rows exist at those levels. One narrative slip should be noted: 1,450 pairs is described as 1,450 unique participants after the merge, which is correct only because each participant has one pair at Level 0.1.

Run #5: Rank-Order Transition Matrix & Cumulative Category Shift Analysis

This run treats the 1-5 answer as ordered categories, using the schema's agreement semantics (agree >= 4, disagree <= 2). The 5x5 transition matrix reproduces the 864 / 311 / 132 classification exactly (above diagonal / diagonal / below diagonal), which independently validates the delta logic and the string/numeric casting. The agree share rose from 32.06% to 72.07% (+40.01 pp) and the disagree share fell from 38.18% to 8.26%, so the shift is a movement of the whole distribution from the lower half to the upper half. Most changes are +1 (30.68%) or +2 (20.96%), and drops of 2 or more are rare (about 2.7%). McNemar's test shows 584 pairs moving into agreement versus 61 moving out (chi2 = 422.46). Its p-value displays as 0 because it is too small to print at the chosen precision. The Wilcoxon sums (W+ = 446,733, W- = 49,773) add up to 996 x 997 / 2 = 496,506, which is internally consistent. This framing is the most meaningful for program staff. It translates the mean change of 1.06 into 'about 4 in 10 more participants now agree they are satisfied with life'.

Domain Nuances & Constraints

(1) Design: this is single-arm observational data. The schema forbids causal claims, and there is no control group. A one-point rise on a global life-satisfaction item is large for a relatively trait-like construct. Because Pre and Post bracket a single workshop, state effects (mood, enthusiasm, social desirability right after a motivating event) and regression to the mean (Pre mean 2.90 is low) may account for part of it. Post is also 'immediately after' measurement, with no durable follow-up. (2) Matching loss: 2,157 Pre rows and 2,145 or so Post rows at Level 0.1 produced only 1,450 pairs. Roughly 700 participants have only a Pre or only a Post row, and 2,177 participants appear in the table overall. Another 143 pairs (about 10%) were lost to NaN cleaning. The 1,307 are therefore survivors who completed both surveys with valid scores. If dropout or non-response is related to how satisfied people felt, the result is biased, and it cannot be generalised to all NIRMAN participants. (3) Zero-coding: 286 zeros (0 = 'not answered') and 1 value > 5 were set to NaN. Treating a zero as a low score would have badly distorted the means. A clustering of zeros in particular batches or phases would indicate an administration gap, and this was not examined. (4) Levels 0.2 and 0.3: the schema allows these levels and links them to Point 2/3 later-stage workshops, yet only one orphan Post row exists at each. Pre/Post change at later stages therefore cannot be assessed from this table, and Demographics' Point_2/Point_3 attendance flags have no matching questionnaire evidence. These later stages are also invitation-gated and self-selected. (5) Scale and ceiling: Post Q3 = 5, so further improvement is capped, and the deltas are bounded at +4. The scale is ordinal, so the mean delta should be read alongside medians and the transition counts. (6) Coverage: the table covers batches 7-17 only, whereas Demographics covers 1-17, so the result says nothing about batches 1-6. The results are also not stratified by batch, and mixing recent and older cohorts could hide differences. (7) Statistical significance: with N = 1,307 any such change will be 'significant'. The effect sizes (dz 0.78, r 0.71) and the percentages are more informative than the p-values. (8) Minor reporting issues: Run 3's remark about 'unequal n' does not apply because only one level contributes, and p-values printed as 0 should be reported as '< 0.0001'.
