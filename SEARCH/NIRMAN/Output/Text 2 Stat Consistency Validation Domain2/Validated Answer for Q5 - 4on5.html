7. How Each of the 5 Runs Analyzed the Data (Explained Simply)

Everyday Explanation of Each Methodology
RUN #1 ✓ Aligned
Crude Two-Proportion Comparison with Direct Gender Standardization

This is the baseline estimate the question literally asks for. It gives crude switch-in rates, the percentage-point gap, the rate ratio and a two-proportion z-test or chi-square (Fisher if any expected cell is below 5). Direct standardization reweights each stream's gender-specific rates to the pooled gender mix. That gives a transparent, model-free gender-adjusted gap that can be compared with the crude gap.

Calculated Finding: Gap −3.60 pp (37.86% vs 41.46%, p=0.23). Within-gender gaps −5.52 (F) and −2.52 (M). Standardized gap −4.10 pp. Verdict: stream association (not significant).
RUN #2 ✓ Aligned
Mantel-Haenszel Stratified Pooling with Breslow-Day Homogeneity Test

This run estimates the gender-adjusted association independently, as a Mantel-Haenszel common odds ratio and a Mantel-Haenszel risk difference pooled across the FEMALE and MALE strata. The Cochran-Mantel-Haenszel test checks whether the adjusted association differs from zero. The Breslow-Day test formally checks for a stream × gender interaction, which Run 1 judges only by eye.

Calculated Finding: Crude OR 0.86; MH OR 0.84 (CI 0.66–1.08); MH RD −4.11 pp; CMH p=0.19; Breslow-Day p=0.64. Verdict: stream association independent of gender.
RUN #3 ✓ Aligned
Logistic Regression with Stream × Gender Interaction and Average Marginal Effects

This run uses a model-based approach. Nested logistic models (stream only; stream + gender; stream + gender + interaction) give a gender-adjusted odds ratio for stream. A likelihood-ratio test checks the interaction. Average marginal effects translate the adjusted association back into percentage points, so the result can be checked against the standardization and MH estimates.

Calculated Finding: Medical OR 0.86 (M1) → 0.84 (M2, p=0.17). Gender-adjusted AME −4.11 pp. Interaction LRT p=0.64. Verdict: stable but non-significant stream association.
RUN #4 ~ Minor Variation
Participant-Level Bootstrap Confidence Intervals for Crude, Within-Gender and Standardized Gaps

This run assumes no particular distribution. It resamples participants with replacement to build empirical confidence intervals for the crude gap, each within-gender gap, the within-stream gender gaps and the standardized adjusted gap. This shows whether the conclusions hold up under sampling variability, which matters most in small Medical cells where normal approximations are unreliable. Wilson score intervals give a second check on each cell rate.

Calculated Finding: Crude gap −3.60 pp (CI −9.85 to 2.05); adjusted gap −4.10 pp (CI −10.61 to 1.52); interaction contrast −3.00 (CI −14.66 to 8.69). Verdict: inconclusive, no rule fired.
RUN #5 ✓ Aligned
Exact Stratified Permutation Test with Gender-Restricted Label Shuffling

This run gives distribution-free, exact-style inference. Shuffling stream labels across all participants yields a crude permutation p-value. Shuffling stream labels only within each gender stratum keeps gender composition fixed. That directly tests whether the stream gap survives once gender is held constant, independent of normal approximations, odds-ratio models or resampling CIs. Per-stratum Fisher's exact tests cover sparse cells.

Calculated Finding: Crude gap −3.60 pp (Fisher p=0.24; permutation p=0.24). Adjusted gap −4.10 pp (stratified permutation p=0.16). Interaction p=0.62. Verdict: (a) stream association retained after gender adjustment.

Domain Overview & Consensus Interpretation

The question asks whether Medical participants in the NIRMAN program (a SEARCH youth social-leadership initiative) are more or less likely than other participants to move to 'Fulltime as a career' for social action between the Pre and Post surveys of the Point-1 workshop. It also asks whether any stream difference is just a by-product of the different gender mix of the streams. The answer needs both tables. The outcome is subjective psychometric data from prod_nirman_questionnaire (Career_Plan_Social_Action_Engagement, Workshop_Level 0.1, Pre vs Post). The stream and gender labels are objective facts from prod_nirman_demographics (Educational_Stream_Category, Gender). The consensus result is: 1,450 matched Point-1 Pre/Post pairs, of which 1,085 were not already full-time at Pre (the at-risk set). All 1,085 matched to demographics. Medical participants switched at 37.86% (198/523) and Non-Medical at 41.46% (233/562). The crude gap is -3.60 pp (rate ratio 0.91, p about 0.23-0.24). The gap keeps its sign within both genders (FEMALE -5.52 pp, MALE -2.52 pp). The gender-standardized gap is about -4.10 pp, slightly wider than the crude gap. In business terms: Medical participants show a slightly lower, statistically indistinguishable rate of moving to full-time social-action intent. Gender composition does not explain this, because women switch more and are over-represented in Medical, so ignoring gender slightly understates the gap. There is no evidence that the stream gap differs between men and women. All five methods reproduce the same numbers, so the real question for a domain reader is how to word a directional but non-significant finding, not whether the arithmetic is right. This is single-arm observational data on self-reported intent, so it supports association only, not proof that the workshop or medical training caused anything.

5-Run Domain Explanations (Schema Context)

Run #1: Crude Two-Proportion Comparison with Direct Gender Standardization

This run is the literal reading of the brief and anchors every other run. It reproduces the base funnel: 1,450 matched Point-1 pairs, 365 already full-time at Pre and excluded, leaving 1,085 at-risk participants. The Medical rate is 37.86% (198/523) and the Non-Medical rate is 41.46% (233/562). The z-test (z = -1.21) and Pearson chi-square (1.47, p = 0.23) agree, and every expected count is far above 5, so Fisher was not required. The gender decomposition shows why standardization widens the gap. Women switch more than men in both streams (+4.82 pp in Medical, +7.82 pp in Non-Medical), and Medical is more female (56.98% vs 48.93%). Women's higher propensity therefore props up the crude Medical rate. Re-weighting both streams to the pooled 53% female / 47% male mix gives 37.66% for Medical and 41.76% for Non-Medical, so the gap goes from -3.60 to -4.10 pp (about 14% wider). Gender is a mild suppressor here, not an explanation. Its verdict of 'stream association' applies the question's directional rule (same sign, similar size, within genders and after adjustment). It correctly notes that this is a direction label and that the female gap is about twice the male gap but untested for interaction in this run.

Run #2: Mantel-Haenszel Stratified Pooling with Breslow-Day Homogeneity Test

Treating FEMALE and MALE as two strata of the same Pre-to-Post switching experience, this run pools the stream contrast across them. The crude OR is 0.86 (0.67-1.10) and the MH OR is 0.84 (0.66-1.08), a change of about 2%, so gender is not a meaningful confounder on the odds scale. The MH risk difference of -4.11 pp matches Run 1's -4.10 pp. The tiny difference comes only from MH weights (n1*n0/n) versus the pooled gender shares. The CMH test (p = 0.19) is non-significant, and the Breslow-Day homogeneity test (p = 0.64) shows no evidence that the Medical gap differs by gender. The female stratum (OR 0.80) and male stratum (OR 0.90) both point below 1 with overlapping intervals. The run's own rule (MH close to crude, same direction in both strata) gives 'stream association independent of gender'. Its narrative honestly notes that the risk-difference shift (about 14%) exceeds the 10% rule of thumb, so the 'independent' label rests on the OR, and that every interval includes the null. Because the questionnaire grain is one row per participant, level and phase, and demographics is one row per participant, the strata contain independent participants, which is what MH assumes.

Run #3: Logistic Regression with Stream × Gender Interaction and Average Marginal Effects

The nested models show what the data say about each demographic factor. Stream alone: Medical OR 0.86 (p = 0.23). Adding gender: Medical OR 0.84 (p = 0.17). Female OR 1.31 (1.02-1.67, p = 0.03; LRT 4.60, p = 0.03). So gender is the only demographic factor with a nominally significant association with switching into full-time social-action intent, and it is more informative than stream. The interaction (OR 0.89, LRT p = 0.64) is not supported, and the M3 within-gender gaps simply reproduce the raw -5.52 pp and -2.52 pp, because a saturated 2×2 model must. The gender-adjusted AME of -4.11 pp matches the standardized and MH estimates, confirming three routes to the same number. The optional batch covariate is the most domain-relevant extra: each later batch is associated with higher odds of switching (OR 1.11, p = 0.013), the Medical OR moves to 0.91 (p = 0.46), and the AME shrinks to -2.24 pp (AIC 1,453.62 vs 1,457.90). That implies Medical participants are somewhat concentrated in earlier batches, which switch less. Part of the stream gap may therefore reflect cohort mix (batch, and probably Workshop_Name instance), not stream itself. This is a Pre-to-Post change measured within the same workshop, so the schema's censoring caveat (recent batches have had less time to realise outcomes) is not the mechanism here. Cohort-to-cohort differences in delivery, facilitation or instrument are the more plausible driver. It is a single exploratory model, so it should be read as a flag, not a result.

Run #4: Participant-Level Bootstrap Confidence Intervals for Crude, Within-Gender and Standardized Gaps

The bootstrap resampled the 1,085 at-risk participants, stratified by stream so the Medical (523) and Non-Medical (562) sizes stayed fixed while gender mix varied. It gives distribution-free intervals: crude gap -3.60 pp (-9.85 to 2.05), adjusted gap -4.10 pp (-10.61 to 1.52), interaction contrast -3.00 pp (-14.66 to 8.69). All 2,000 resamples were valid, since the smallest cell is 225. In domain terms, the data are compatible with anything from a roughly 10 pp lower to a 2 pp higher Medical switch-in rate. The adjusted and crude gaps shared a sign in 97% of resamples, so the widening after adjustment is stable even though the gap itself is imprecise. The 'share explained' of -0.14 is negative (adjustment widened the gap) and its CI (-1.26 to 1.21) is uninformative because the crude gap is near zero, so it should not be interpreted. This run is the only one marked isAligned = false, but the disagreement is semantic, not numerical. Its verdict rule requires the adjusted CI to exclude 0 before the label 'stream association' can be used, so with the CI spanning 0 no rule fires and it reports 'inconclusive'. The question's own Step 5 only asks for same direction and similar size. Both readings describe the same estimates, and Run 4's wording is the more conservative one.

Run #5: Exact Stratified Permutation Test with Gender-Restricted Label Shuffling

This run asks directly: if stream labels were unrelated to switching, how often would shuffling produce a gap this large? Shuffling across everyone gives p = 0.24 (Fisher p = 0.24, same). Shuffling only within each gender stratum holds the gender mix fixed and gives p = 0.16 for the adjusted gap. The p-value falls slightly because gender explains part of the outcome variance (women switch more), which removes noise once it is held constant. This matches Run 3's M2 Medical p = 0.17. Neither is significant. Per-stratum Fisher tests give FEMALE p = 0.20 and MALE p = 0.58, so the larger female gap is not statistically distinguishable from the male gap (interaction permutation p = 0.62). Within streams, the female advantage is borderline in Non-Medical (+7.82 pp, p = 0.07) and clearly non-significant in Medical (+4.82 pp, p = 0.28). The run applies the question's verdict rule (a), noting that the adjusted/crude ratio is 1.14, and it states that this label means direction was preserved, not that a significant difference was established. All its inferential machinery (Fisher via hypergeometric log-factorials, seeded mulberry32 Fisher-Yates shuffling, 10,000 permutations) is robust to the fact that the outcome is a binary derived flag from an ordinal self-report.

Domain Nuances & Constraints

1) Wording of the verdict. No test reaches p < 0.05 (crude p 0.16-0.24, all intervals include 0). The data also cannot exclude a gap of about 10 pp in either direction. With 523 vs 562 participants and a base rate near 40%, the design can reliably detect only gaps of about 8 pp or more, and the interaction test has even less power. 'Stream association' is therefore a statement about direction and stability after adjustment, not an established difference. 'Weak, non-significant, direction-consistent' (Runs 1-3, 5) and 'inconclusive' (Run 4) are two descriptions of the same evidence. 2) The sensitivity check is a no-op. Restricting to Workshop_Batch_Number 11-17 leaves N = 1,085. This is probably a data-lineage fact, not a bug. The schema ties the Career_Plan switch analysis to Point 1 in batches 11-17, and the questionnaire spans batches 7-17, so all at-risk Point-1 pairs appear to come from batches 11-17. This is an inference, so print the batch distribution to confirm. Either way, the check provides no independent robustness. 3) Cohort confounding. Run 3's batch-adjusted model shrinks the Medical gap to -2.24 pp. Cohort timing, Workshop_Name (A-H) and delivery context are plausible confounders. The YAML censoring rule (recent batches have less time to realise outcomes) applies to long-term outcomes such as Current_Status_Of_Work, not to this immediate Pre-to-Post intent shift. 4) Selection on the baseline. The at-risk set conditions on is_fulltime_pre == 0, which removes 365 participants (1,450 minus 1,085). If the proportion already full-time at Pre differs by stream, the at-risk Medical and Non-Medical groups are not like-for-like. That could produce a ceiling effect or regression to the mean. 5) Outcome definition. 'Not yet decided / confused' is coded 0 here (as the question requires), although the YAML treats it as null in ordinal models.   2. Cohort timing may confound the result. In Run 3's batch-adjusted model, later batches had higher switching (OR 1.11 per batch, p = 0.013). The medical OR moved to 0.91 and the AME shrank to about −2.24 pp. Batch adjustment is a bigger threat to the gap than gender adjustment.
  3. Null count mismatch. Four runs dropped 1 null engagement row, against 4 expected. Run 1 notes that the 4 is table-wide and 1 falls in Point-1, so this is probably benign, but it is worth confirming.
  4. Design limits. The data are single-arm and observational, with self-reported intent. Only gender is adjusted for, "Not yet decided" is coded as 0, and recent batches had less follow-up time.
  5. Agreement is not full independence. All five runs use the same data, base and cleaning, so their agreement shows that the conclusion does not depend on the statistical method. It does not replicate the finding on new data.

3. Does it matter that one run didn't converge?

Not materially, and Run 4 did not disagree on the evidence.

  • Run 4 produced the same estimates as the others: crude gap −3.60 pp, adjusted gap −4.10 pp, and the same within-gender gaps.
  • The difference is only in the label. Its verdict rule required the adjusted-gap CI to exclude 0. The adjusted CI was −10.61 to +1.52, so it reported "inconclusive". The other runs' rules only required same direction and similar size.
  • Runs 1, 2, 3 and 5 also found the stream gap non-significant. They called it a "stream association" under looser criteria, so their label is arguably too strong.

Run 4's "inconclusive" is therefore the most statistically cautious reading, and it is consistent with everything else. The right way to report the result combines the two:

Medical participants showed a modestly lower switch-in rate (−3.60 pp crude, about −4.10 pp gender-adjusted). The direction is consistent across genders and is not explained by gender mix, but the difference is not statistically significant and the data are compatible with no difference.

The dissent would matter if it had shown a different estimate, a sign flip, a significant interaction, or evidence of a gender-composition effect. None of these occurred.

4. Business implications

  • Don't act on the stream difference as if it were real. Treat it as a hypothesis to monitor.
  • Don't prioritize gender-based targeting to address the stream gap, since it does not explain it.
  • Check batch/cohort timing before drawing conclusions, and resolve the sensitivity no-op.
  • If the stream question is important, more data are needed. The current CI cannot rule out a gap of about 10 pp in either direction.
