Domain Overview & Consensus Interpretation

The question asks how many Batch 14 participants in NIRMAN, SEARCH's youth social-leadership program, say they plan to pursue social action 'Fulltime as a career' at the Pre and Post stage of the Point 1 workshop. 5-Run Domain Explanations (Schema Context)

Run #1: Direct Danfo.js Filter, Unique-Count & Suffix Inner-Merge Baseline

This run implements the schema's own pre_post_pairing recipe: split by Workshop_Phase, suffix _pre/_post, inner-merge on Participant_Id plus Workshop_Level. It applies the mandated casts (Participant_Id as string; Workshop_Level compared numerically, here with a 1e-9 tolerance on 0.1) and filters to Batch 14 and Point 1. Unique counts of Participant_Id, not row counts, are correct for 'how many participants'. The result is Pre 28/148, Post 66/148, the 26/40/2/80 split, net change +38 and switch-in 40/120 = 33.33%. Each category is a participant-level pattern: 26 people held a full-time plan before and after, 40 moved into it, 2 moved out, and 80 never held it. The switch-in rate is conditional on pre = 0, so the 26 already-committed people cannot 'switch in' and are correctly excluded from the denominator. The 2 who switched out are the only evidence of regression among the 28 Pre full-timers. This run is the reference the others are checked against.

Run #2: Pure JavaScript Set-Algebra Reconstruction (No DataFrame Merge)

This run replaces dfd.merge with Map/Set operations. Matched participants are the intersection of Pre and Post ID sets, and unmatched participants are the set differences. It guards against DataFrame-library artefacts such as suffix collisions and dtype coercion of the numeric-looking Participant_Id. It also guards against the NaN engagement values becoming the literal string 'NaN'. The set-based duplicate check returned nothing, as the schema's grain predicts, because one row exists per (Participant_Id, Workshop_Level, Workshop_Phase). The 'first non-null' fallback therefore never fired. Its switch-in denominator (switched in + stayed not full-time = 120) is algebraically the same as 'pairs with pre = 0'. The identical 28/66/26/40/2/80 and 0 Pre-only/0 Post-only show the result does not depend on the merge implementation. The Batch 14 Pre and Post cohorts are the same 148 people.

Run #3: 2x2 Contingency Cross-Tabulation with McNemar Paired Test & Marginal Homogeneity Check

This run arranges the matched pairs as a Pre × Post table: a = 26 (stayed full-time), b = 2 (switched out), c = 40 (switched in), d = 80 (stayed not full-time). The marginals reconcile with the unpaired counts: Pre full-time a+b = 28, Post full-time a+c = 66, Pre not full-time c+d = 120, Post not full-time b+d = 82. Net change c − b = +38 equals the unpaired 66 − 28 because the two cohorts are identical. McNemar tests only the discordant pairs (b + c = 42), of which 40 moved toward full-time. With a continuity-corrected χ² of (|2−40|−1)²/42 ≈ 32.6, the Pre→Post shift is very unlikely to be sampling noise. The paired difference of 38/148 ≈ 25.68 percentage points is a within-person change in stated plan. For the domain, the 106 people whose full-time status did not change (26 + 80) carry no information on this question. The chi-square and exact binomial p-values agree. The test establishes statistical association in a single-arm design, not that the workshop caused the change.

Run #4: Participant-Level Deduplication & Grain-Audit Aggregation

This run audits the declared grain of the questionnaire table. It found 296 rows, 296 distinct (Participant_Id, Workshop_Level, Workshop_Phase) keys, and no duplicates or conflicts. This confirms that no many-to-many merge inflation is possible here. Pivoting to wide format (engagement_pre, engagement_post) is mathematically the same as the suffix-and-inner-merge recipe. All 148 participants are in both phases with non-null engagement, so nothing was dropped. Its narrative also gives a response-level breakdown ('Volunteering frequently' 52→16, 'Monetary contribution' 8→0, 'Part time' 51→65). That is plausible for the 1–5 ordinal scale and suggests the full-time gain comes largely from people moving up from lower-intensity engagement levels. However, that breakdown was not part of the requested outputs and is not cross-checked by the other runs, so treat it as supplementary. It is not part of the consensus answer. The remark that unpaired and matched figures might diverge in other batches or levels is correct, because batches may have attrition between Pre and Post.

Run #5: Bootstrap Resampling & Wilson Interval Stability of Transition Shares

This run keeps the deterministic counts and adds uncertainty. It uses Wilson intervals for Pre (13.43%–25.98%) and Post (36.82%–52.64%), whose non-overlap is consistent with a real shift. It also uses a 2,000-draw participant-level bootstrap (seeded mulberry32(42)) over the 148 matched pairs. The net change of +38 has a 95% interval of about 27–49 (18.24–33.11 pp), and the switch-in rate is 33.33% (Wilson 25.53%–42.17%). This matters because Batch 14 is a single cohort of modest size, one of 11 batches in the questionnaire. The intervals describe sampling variability within this cohort, not generalisability to other batches or causal effect. The 'Switched out' interval (0–3.38%) touches zero, reflecting its tiny count of 2. Bootstrap medians equal the point estimates because the resampling is centred on the observed sample, and the point estimates themselves come from the full-sample deterministic counts.
