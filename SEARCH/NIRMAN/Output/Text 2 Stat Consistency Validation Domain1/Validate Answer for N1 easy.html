How the Project Schema Explains & Validates This Answer:

The question asks whether self-reported global life satisfaction (Metric_Life_Satisfaction_Global, 'All things considered I am satisfied with my life', a 1–5 agreement item in the wellbeing_self theme) changed between the Pre and Post phases of the Point-1 NIRMAN workshop (Workshop_Level 0.1). The population is a narrow slice: Batch 14, FEMALE, Educational_Stream_Category == 'Medical' (a category that excludes Pharmacy and is not the same as Educational_Stream 'Medical / Public Health'). Demographics, which has one row per Participant_Id, defines who is in the cohort (N = 52). The questionnaire, which has one row per Participant_Id × Workshop_Level × Workshop_Phase, supplies the psychometric Pre/Post measurements. The effective N moves through the funnel 52 cohort → 52 Pre/Post pairs at Point 1 → 51 valid pairs. The one exclusion, ID 14045, has ls_pre = 0, which the questionnaire schema defines as 'not answered' and not as a low score. That participant's Post value is a valid 5. All five runs converge on the same substantive finding. Mean life satisfaction rose from 3.02 to 3.94, a mean delta of +0.92 (SD 1.20, median +1), with 33 improved, 13 unchanged and 5 declined. The Wilcoxon (z = −4.24, p = 2.2e-5), paired t (t(50) = 5.50, p = 1.3e-6) and exact sign (p = 4.3e-6) tests are all significant. Effect sizes are dz = 0.77 (medium) and rank-biserial r = 0.77 (large). The schema frames the data as single-arm observational, so the finding is a significant Pre-to-Post association or change, not evidence that the workshop caused it.
