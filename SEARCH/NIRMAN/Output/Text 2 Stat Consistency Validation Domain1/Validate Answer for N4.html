Domain Overview & Consensus Interpretation

The question asks how satisfied female Medical-stream NIRMAN participants say they are with their lives right after a workshop, and how that varies across the Point 1, Point 2 and Point 3 workshops. It also asks how Point 1 Post scores compare with the same women's Pre scores. The cohort is defined from the Demographics table (prod_nirman_demographics: one row per Participant_Id, 2,890 rows, batches 1-17) with Gender == 'FEMALE' and Educational_Stream_Category == 'Medical'. That rollup excludes Pharmacy and must not be mixed with Educational_Stream = 'Medical / Public Health'. The outcome comes from the Questionnaire table (prod_nirman_questionnaire: grain Participant_Id x Workshop_Level x Workshop_Phase, 4,304 rows, batches 7-17). The outcome is Metric_Life_Satisfaction_Global, the agreement-scale item 'All things considered I am satisfied with my life' (1 = strongly disagree, 5 = strongly agree; agree >= 4, disagree <= 2). The consensus funnel follows the schema's one-to-many join. 749 cohort women in Demographics became 1,180 questionnaire rows from 627 women. The other 122 women have no questionnaire rows, consistent with the batch 1-6 gap and non-participation. Of the 1,180 rows, 561 are Post rows (368 / 150 / 43 at Levels 0.1 / 0.2 / 0.3) from 472 unique women. The 89 extra rows (561 - 472) come from women who completed Post surveys at more than one level. The schema's cleaning rule (0 = not answered, > 5 invalid) removed 16 Post rows, all zeros, leaving 545 valid Post rows from 456 women. Post satisfaction is moderately high: mean 3.82, median 4, SD 1.04, 65.69% satisfied and 11.19% dissatisfied. In the Point 1 paired view (N = 352) the mean moves from 2.86 to 3.84 (+0.98). In this single-arm observational program data, that is an association and an observed change, not a demonstrated workshop effect.

5-Run Domain Explanations (Schema Context)

Run #1: Direct Parametric Aggregation Baseline

This run applies the schema rules literally: cast Participant_Id to string, filter Demographics before the inner join, keep Post, then set 0 and values above 5 to NaN. It gives the reference funnel of 749 -> 1,180 rows -> 627 women -> 561 Post rows -> 545 valid, with 16 zero-coded drops (15 at Level 0.1, 1 at Level 0.3). The 16 zeros are the 'not answered' non-responses the schema warns about, and no value above 5 appeared. Counting unique participants before cleaning (472: 368 / 150 / 43) matches the wording 'filled a Post survey', while 545 is a row-level effective N. The grain is one row per participant per level per phase, so per-level unique counts equal per-level row counts (368 + 150 + 43 = 561). The overall unique count (472) is lower because 89 women completed Post surveys at more than one level. The descriptive results (mean 3.82, median 4, SD 1.04, 65.69% satisfied, 11.19% dissatisfied) describe the Post state. The paired Level 0.1 result (352 pairs, 2.86 -> 3.84, +0.98) is Pre-to-Post association within the Point 1 workshop.

Run #2: Median, IQR & Non-Parametric Distribution Profile

The 1-5 agreement item is ordinal and bounded, so the median and quartiles are the more defensible summaries. The overall median is 4 (Q1 3, Q3 5, IQR 2), and the median is 4 at every level. The overall mode is 4. At Level 0.3 the mode is 5 (16 of 42, 38.1%), which fits that group's higher mean (4.00) but rests on a small N. The paired result (216 improved, 91 unchanged, 45 declined, median delta +1) shows the +0.98 mean shift is a broad movement, not a few large jumps. The Wilcoxon test on 261 non-zero pairs (W+ 29,664, W- 4,527; the rank sums add to 261 x 262 / 2 = 34,191) is consistent with that. Because paired differences take only a few integer values, ties are heavy and the tie-corrected normal approximation is appropriate. The reported z of -10.48 reflects W = min(W+, W-); the direction is upward. The p-value indicates a systematic Pre-to-Post difference in this program cohort and says nothing about cause. Run 2 also adds the before and after cleaning participant counts (472 / 456), which makes the 16 non-responders visible.

Run #3: Volume-Weighted Pooled Estimation Across Workshop Levels

This run treats the three levels as sub-populations of the Post survey. Level 0.1 holds 64.77% of valid rows, Level 0.2 27.52% and Level 0.3 7.71%. The overall mean, counts and SD rebuilt from level components equal the direct values (3.82, 1.04, 15/46/126/195/163), as expected because the overall data is the union of the three levels. The unweighted mean of level means (3.85) is only 0.03 higher, so no single level distorts the headline. The median cannot be pooled from level medians and must be computed directly. The run also makes a structural point: because Point 2 and Point 3 Post rows have no Pre counterpart in this cohort, only Point 1 supports pairing. Its statement that cleaning removed 33 rows (16 Post, 17 Pre) shows the 0 = not answered issue affects both phases at about 2.7-2.9%. Roughly 61% of pairs improved, 26% stayed the same and 13% declined.

Run #4: Trimmed-Mean & Bootstrap Sensitivity Analysis

This is a stability check. On a 1-5 attitude item, trimming the 5% tails drops the 15 'strongly disagree' answers and 12 of the 46 'disagree' answers at the low end (27 rows), and 27 of the 163 'strongly agree' answers at the high end. Because the low-end values lie further from the centre than the high-end values, the trimmed mean (3.88) rises slightly above the plain mean (3.82). These low scores are genuine responses (the invalid 0s are already removed), so the trimmed value is a sensitivity indicator, not a better estimate. The bootstrap intervals (overall mean 3.73-3.91; Level 0.1 3.74-3.95; Level 0.2 3.53-3.87; Level 0.3 3.69-4.29; paired delta 0.82-1.12) show the level differences overlap. The Level 0.3 gap above the other levels is therefore not distinguishable from noise at N = 42. The CIs are reproducible because the PRNG seed is fixed (mulberry32, seed 42). The resampling treats rows as independent, although 89 women contribute more than one row, so the intervals are slightly optimistic. No group falls below N = 30, so none is flagged low-precision.

Run #5: Cumulative Frequency & Rank-Order Reconstruction

All statistics are rebuilt from the 1-5 frequency table, which exposes the shape of the distribution. Overall the counts are 15 / 46 / 126 / 195 / 163. The median falls at rank 273, where cumulative counts run 15, 61, 187, 382, so it is 4. The top-two-box share is (195 + 163) / 545 = 65.69% and the bottom-two-box share is 61 / 545 = 11.19%. The derived values match direct computation exactly, which confirms that the 545 cleaned rows are internally consistent. The 5x5 transition table and the 61.36% up / 25.85% same / 12.78% down split (216 / 91 / 45 of 352) show where the Pre-to-Post movement occurs. Level 0.3 is the only group whose mode is 5, but N = 42 makes that fragile. The run's explanation of the 352 vs 353 gap (one fewer Post score of 5) is not verifiable from the dossier; Run 4 states only that a Post respondent presumably lacks a valid Pre score. Run 5 also notes that regression to the mean and self-selection could contribute to the Pre-Post change.

Tied |delta| values get an average rank of RANK() + (t-1)/2. The tie correction Σ(t³−t)/48 equals Σ over rows of (t²−1)/48.

sql
WITH nz AS (
    SELECT delta, ABS(delta) AS abs_d
    FROM   v_paired_01 WHERE delta <> 0                     -- exclude zero deltas
),
ranked AS (
    SELECT delta, abs_d,
           RANK()  OVER (ORDER BY abs_d)                    AS r,
           COUNT(*) OVER (PARTITION BY abs_d)               AS t,
           RANK()  OVER (ORDER BY abs_d)
             + (COUNT(*) OVER (PARTITION BY abs_d) - 1) / 2.0 AS avg_rank
    FROM nz
),
agg AS (
    SELECT COUNT(*)                                        AS n_nz,
           SUM(avg_rank) FILTER (WHERE delta > 0)          AS w_plus,
           SUM(avg_rank) FILTER (WHERE delta < 0)          AS w_minus,
           SUM(t*t - 1)                                    AS tie_sum   -- = Σ(t³ − t) over groups
    FROM ranked
)
SELECT  n_nz, w_plus, w_minus,
        (LEAST(w_plus, w_minus) - n_nz*(n_nz+1)/4.0)
        / SQRT( n_nz*(n_nz+1)*(2*n_nz+1)/24.0 - tie_sum/48.0 ) AS z
FROM    agg;
-- Expected: n_nz 261, W+ 29,664, W- 4,527, z ≈ -10.48

The two-sided p-value 2*(1-Φ(|z|)) needs a normal CDF, which most SQL engines lack. Compute it in the application layer, or use a built-in if available (for example NORMSDIST in some warehouses). The dossier reports p < 0.01.

WITH cum AS (
    SELECT grp, score, c,
           SUM(c) OVER (PARTITION BY grp ORDER BY score) AS cum_c,
           SUM(c) OVER (PARTITION BY grp)                AS n
    FROM   v_freq
