Run #1: Baseline Logistic Regression (tf.sequential single dense sigmoid unit) with Wald + Bootstrap Odds-Ratio CIs

For the strict-leaver comparison (~136 Sustainers vs ~24), the base rate is about 85%, and quasi-separation is likely because Gender/State cells will be sparse.

Run #2: Multi-Layer Perceptron with Dropout + Permutation Importance & Partial Dependence

No output exists. The MLP asks whether Gender, Maharashtra and age interact in predicting sustained social action. The data are small (~270-280 rows, 3-4 predictors, two of them binary), so a 16-8-1 network is over-parameterised relative to the information. Run #3: Z-Score Normalised, Batch-Normalised Logistic Model with Expanded State Encoding and Exposure Controls

Run #4: L2 (Ridge) and L1 (Lasso) Penalised Logistic Regression with Cross-Validated Lambda

No output exists, and unlike the other runs this one returned no narrative at all, only the rewritten queries. The rationale is sound for this schema: the strict-leaver group (~24) and the Medical cell are small, so unpenalised ORs can inflate under separation. A coefficient that stays on the same side of 1 under ridge is only a robustness check, not confirmation of a social-sector retention mechanism.

Run #5: Bootstrap-Bagged Ensemble of Logistic Models with Batch-Era Segmentation

No output exists. Bagging 50 stratified resamples gives an empirical OR distribution and direction stability (% of resamples with OR > 1), which suits the small groups.
