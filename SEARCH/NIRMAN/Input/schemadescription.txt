DOMAIN
--------------------------------------------------------------------
NIRMAN is a youth social-leadership program run by SEARCH. It identifies
and nurtures young people towards social-change careers. Two kinds of
data exist:
  - OBJECTIVE FACTS about a person (who they are, where they are from,
    which cohort, what work they do today)  -> Demographics table
  - SUBJECTIVE PSYCHOMETRICS (mindset, purpose, aspirations, insecurities,
    income expectations), captured Pre and Post each workshop
    -> Questionnaire table
Typical questions: cohort counts and distributions, Pre vs Post change,
sustained social action, predictors of a full-time social-impact career.
This is single-arm observational data: report association and change,
never causal proof that the workshop caused an outcome.

THE TWO TABLES
--------------------------------------------------------------------
Table 1  prod_nirman_demographics
         1 row per Participant_Id (unique), 2890 rows.
         Identity, cohort/batch, education, current work outcome, native
         geography, person-years of social action, Point-2/3 follow-up.
	 Users may refer to this prod_nirman_demographics Table as Demographics Table

Table 2  prod_nirman_questionnaire
         1 row per (Participant_Id, Workshop_Level, Workshop_Phase),
         4304 rows, 2177 participants, 181 columns.
         Pre/Post survey items on career preference, life criteria,
         insecurities, finances, and ~14 mindset themes.
	 Users may refer to this prod_nirman_questionnaire Table as Questionnaire Table

JOIN RULE
--------------------------------------------------------------------
Join key: Participant_Id (demographics) <-> Participant_Id (questionnaire).
  - Cast Participant_Id to STRING in BOTH frames before any merge, groupby or comparison. It looks numeric (1001-17176) but is a key.
  - Relationship is one-to-many: demographics 1 row -> questionnaire many rows.
  - Not every participant appears in both tables. Joining shrinks and skews N - always recompute and report the effective N after a merge.
  - Note: Both tables contain same column names: `Participant_Id`, `Participant_Name`, `Workshop_Name`, and `Workshop_Batch_Number`
  - Demographics covers batches 1–17; questionnaire only 7–17.  
  - In both tables, Workshop_Name is one of these values: A,B,C,D,E,F,G,H
